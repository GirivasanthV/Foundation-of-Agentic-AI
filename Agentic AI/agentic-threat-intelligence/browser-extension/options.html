Automatic analysis and privacy settings

Screenshot privacy

When screenshot analysis is enabled, the visible area of active public webpages is sent to your configured SentinelAI backend and may be forwarded to your configured Azure vision model. Add private or sensitive domains to the exclusion list.

The extension scans only the active HTTP/HTTPS tab. It never uploads file contents; the file checker calculates SHA-256 inside the browser and sends only the hash and basic filename metadata.
